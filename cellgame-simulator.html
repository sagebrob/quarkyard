Cell Cycle Simulator — Long-Run Results

This page runs the exact same rules as the game itself — the same checkpoint math, the same Cellular Chance deck — but plays it out automatically, over and over, without needing anyone to roll dice. Use it to see what the checkpoint (Round 1) vs. mutated-p53 (Round 2) conditions actually do to the odds if the game were played a huge number of times.

Each run plays that many cells through Round 1 and that many through Round 2, using fresh dice every time.

Round 2 — Individual Cell Journeys

For each cell, how many Chance cards said "p53 is working well," how many said "p53 is not working," and how many of those actually skipped an honest checkpoint check. The point: a card saying p53 "isn't working" is usually just a setback — it takes a checkpoint actually being skipped to cause cancer.
